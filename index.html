MIKEJ. GM

An AI-assisted fantasy football general manager built to help one manager make better, data-informed decisions in a private Yahoo Fantasy Football league.

What it does

  • Reviews league scoring and roster settings
  • Analyzes team rosters, weekly matchups and player performance
  • Evaluates free agents and waiver-wire opportunities
  • Recommends lineup decisions, potential acquisitions and FAB bids
  • Presents recommendations for human review before any action

Yahoo Fantasy Sports data use

The project seeks authorized, read-only Yahoo Fantasy Sports API access to retrieve league settings, team and player information, roster status, matchups, available players and transaction information where supported. Data is used solely to generate analysis and recommendations for the account owner.

Access and scope

MIKEJ. GM is an independent project in development for one user managing one team in one private fantasy football league. It is not a public service, does not sell or redistribute Yahoo Fantasy Sports data, and does not submit transactions or change lineups. The manager performs all changes manually in Yahoo Fantasy Sports.

MIKEJ. GM is an independent personal project and is not affiliated with, endorsed by, or sponsored by Yahoo.
