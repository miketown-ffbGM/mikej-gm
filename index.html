About MIKEJ. GM

MIKEJ. GM is an independent, non-commercial, single-user project for fantasy football decision support. It aims to retrieve authorized read-only Yahoo Fantasy Sports data about league rules, rosters, matchups, player availability and transactions, where available.

There is no Yahoo API connection in this demo. No Yahoo credentials, private league data, or API tokens are collected or stored by this site. Review drafts are stored locally in your browser and can be cleared.

All recommendations are reviewed by the manager. Yahoo roster changes and transactions must be performed manually in Yahoo Fantasy Sports. MIKEJ. GM is not affiliated with, endorsed by, or sponsored by Yahoo.
